Lista de Projetos Feitos

Lista de alguns projetos que foram feito ate o presente momento para praticar o que foi ensinado no curso do professor guanabara


➣Projeto Android - Primeiro projeto pratico realizado no curso, o projeto conta um pouco da historia de como o sistema operacional android foi criado.


➣Projeto Cordel - Segundo projeto pratico realizado. O Projeto mostra um cordel que pode retratar como e a vida atual comparada com a vida antigamente.


➣Projeto Vanguards - Primeiro projeto criado de forma autentica, esse projeto foi criado com o intuito de praticar tudo o que foi ensinado até aquele presente momento, juntando tudo em um unico site. O Projeto tem como base principal um jogo da plataforma Roblox chamado anime vanguards.


➣Projeto Essentials - Segundo projeto realizado de forma autentica, o projeto foi criado com o ituito de juntar diversos softwares e aplicativos que são muito uteis e até essenciais para o usuario durante o seu dia a dia. Alem disso foi incluido um tutorial de instalação do sistema operacional Windowns, e de como remover varios aplicativos inuteis que acabam ocupando espaço ou ate atrapalhando o usuario.


➣Projeto Redes Sociais - Terceiro Projeto do curso. Um projeto pratico com o instuito de praticar e tambem mostrar as redes socias.
