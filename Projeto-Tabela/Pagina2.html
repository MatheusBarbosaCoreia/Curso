Como Intalar e Otimizar o Windowns 10/11




1° Passo: Criando Pendrive Bootavel



Baixe a ISO original do Windowns 10/11 direto do site da Microsoft (Caso não funcione utilize oos.click ).

Apos baixar a ISO, baixe o programaRufus para criar um pendrove bootável. Criando um pendrive bootável:

  • Abra o programa Rufus (Apos a intalação dele)
  • Selecione a ISO baixada
  • Escolha o esquema de partição adequado (GPT para computadores/notebooks modernos, MBR para mais antigos).
  • Utilize funções do Rufus para remover exigências como TPM2 e Secure Boot.

2° Passo: Criando autounattend


Enquanto o pendrive bootavel esta sendo criando, acesse o site autounattend para gerar o arquivo autounattend.xml. Este arquivo serve para automatizar toda a instalação do Windowns, evitando as telas manuais (Porem ainda sera necessario criar a partição).Para melhor experiencia sigua os passos do video. Apos o termino baixe o arquivo.


3° Passo: Selecionando Aplicativos no Nininte


Acesse o site doNinintee selecione o que deseja instalar. Com tudo selecionando baixe o nininte.


4° Passo: Colocando os Scripts automatizados


Apos a criação do arquivo .xml e do nininte coloque os arquivos dentro do pendrive bootavel que foi criado com o Rufus


5° Passo: Instalação do Windowns


Com tudo configurado, certifique de salvar seus documentos e arquivos pessoais antes de iniciar a instalação.

Feito isso reinicie o computador e acesse a bios (Aperte a tecla "del" ou "F12", as teclas sao diferentes para cada computador), entrando na bios procure por "boot" e mude a prioridade de boot colocando o pendrive bootavel. Feito isso reinicie e espere entrar na tela de instalação do windows 10/11.

Ao entrar na tela de instação do Windowns 10/11, selecione onde deseja instalar. Apos selecionar aguarde ate que a instalação seja concluida.


6° Passo: Configurando o Sistema


Com o Sistema (Windowns) ja instalado, abre o gerenciador de arquivos, acesse o pendrive e execute o nininte para que instale o que foi selecionado. Aguarde um pouco ate que a instalação seja concluida.
